Generative AI Algorithms (Emphasized)

Generative AI creates new content—text, images, video, or data—from learned patterns. Key algorithms and their applications:

GPT (Text Generation)

Decoder-only transformers that predict next tokens autoregressively. Powers ChatGPT, code assistants, and content creation.

Diffusion Models

Image generation by reversing noise. Powers DALL-E, Stable Diffusion, Midjourney for text-to-image creation.

GANs

Generator + Discriminator adversarial training. Image/video synthesis, deepfakes, art generation, data augmentation.

Variational Autoencoders (VAEs)

Encode data to latent space, decode to generate. Drug discovery, anomaly detection, data generation.

Chatbots Code Generation Image Creation Drug Discovery Content Summarization Video Synthesis

Algorithm Details (10 Algorithms)

Decision Trees
Type: Supervised
Domain: Tabular Data
Use Cases: Credit approval, medical diagnosis, customer churn, fraud detection
Creates hierarchical decision rules by recursively splitting data on feature values. Maximizes information gain at each split.
Random Forests
Type: Supervised
Domain: Tabular Data
Use Cases: Predictive maintenance, stock prediction, real estate pricing, disease risk
Ensemble of Decision Trees with random subsets. Voting/averaging reduces overfitting and improves accuracy.
Gradient Boosting
Type: Supervised
Domain: Tabular Data
Use Cases: Kaggle competitions, CTR prediction, search ranking, insurance claims
Sequential models where each corrects previous errors. XGBoost/LightGBM are optimized implementations.
K-means Clustering
Type: Unsupervised
Domain: Tabular Data
Use Cases: Customer segmentation, image compression, document clustering, anomaly detection
Partitions data into k clusters by iteratively assigning points to nearest centroids. Minimizes within-cluster variance.
CNNs
Type: Supervised
Domain: Computer Vision
Use Cases: Medical imaging, autonomous vehicles, facial recognition, defect detection
Convolutional layers detect local patterns (edges, textures). Hierarchical features from low-level to high-level objects.
Transformers (GPT, BERT)
Type: Supervised
Domain: NLP
Use Cases: Translation, chatbots, summarization, sentiment analysis, content moderation
Self-attention processes all words simultaneously. GPT (decoder-only) for generation; BERT (encoder) for understanding.
GANs
Type: Unsupervised
Domain: Generative AICV
Use Cases: Deepfakes, art generation, data augmentation, style transfer, game assets
Generator creates fake data; Discriminator distinguishes real from fake. Adversarial training produces realistic outputs.
Diffusion Models
Type: Unsupervised
Domain: Generative AICV
Use Cases: DALL-E, Stable Diffusion, image editing, product design, medical synthesis
Learns to reverse noise-adding process. Starts from noise, denoises iteratively to create high-quality images.
Support Vector Machines
Type: Supervised
Domain: TabularNLP
Use Cases: Spam detection, image classification, bioinformatics, face detection, stock prediction
Finds optimal hyperplane maximizing margin between classes. Kernel functions handle non-linear relationships.
PCA
Type: Unsupervised
Domain: Tabular Data
Use Cases: Data visualization, feature engineering, image compression, genomics, risk analysis
Identifies principal components capturing maximum variance. Reduces dimensionality while preserving information.

Reflection on Learning Experience

Creating this visual framework deepened my understanding of the AI/ML landscape. I recognized that algorithms cannot be neatly boxed into single categories—many span multiple domains. CNNs are primarily for computer vision but can adapt to tabular data; Transformers revolutionized NLP and are now foundational to generative AI models like GPT.

I gained appreciation for how machine learning has evolved: traditional algorithms like Decision Trees and SVMs remain powerful for structured data, while Transformers and Diffusion Models represent breakthroughs in unstructured data and generative tasks. Researching real-world use cases—Gradient Boosting dominating Kaggle, CNNs enabling medical imaging, Diffusion Models powering creative tools—made theoretical concepts tangible.

This artifact demonstrates my ability to synthesize complex technical concepts into clear visual frameworks and communicate algorithmic relationships—essential skills for AI/ML professionals. The framework serves as a valuable reference for selecting appropriate algorithms for specific problem types throughout my studies and career.
