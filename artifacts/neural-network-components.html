Components Covered

  • Layers: Input, hidden, and output layers and how data flows through the network.
  • Neurons: Basic computation units that apply weights, bias, and activation to inputs.
  • Weights: Learned parameters that determine the strength of connections between neurons.
  • Activation Functions: ReLU, Sigmoid, Tanh—introducing non-linearity and shaping outputs.
  • Loss Functions: MSE, Cross-Entropy—measuring prediction error to guide learning.
  • Optimization Algorithms: Gradient descent, Adam—updating weights to minimize loss.

Neural Network Playground

This assignment included hands-on practice using the Neural Network Playground to train models with different data types, noise levels, features, and layer configurations.
